ФОРМУЛА РАСЧЕТА:

Для ИЛИ-связей (несколько независимых путей к одной книге):
P(книга) = 1 - ∏(1 - P_i), где P_i - вероятности каждой связи

Для И-связей (все условия должны быть выполнены):
P(книга) = коэффициент связи, если ВСЕ условия выполнены
P(книга) = 0, если хотя бы одно условие не выполнено

Комбинированный случай (И-связи + ИЛИ-связи):
Сначала рассчитываются все применимые связи,
затем объединяются по формуле ИЛИ

1. Система корректно работает для разных профилей пользователей
2. И-связи позволяют точно фильтровать по множественным критериям
3. ИЛИ-связи дают гибкость в подборе при частичном совпадении
4. Высокие вероятности (>0.7) означают сильную рекомендацию
5. Система учитывает приоритеты через коэффициенты связей
