ВЫВОДЫ - НЕАДЕКВАТНЫЕ СВЯЗИ:

1. КРИТИЧНО НЕАДЕКВАТНЫЕ:
   - Романтика(0.1) -> Шерлок Холмс
     Причина: Жанровая несовместимость (детектив != романтика)
   
   - Триллер(1.0) -> Триллер №1
     Причина: Коэффициент 1.0 приводит к превышению вероятности

2. ТРЕБУЮТ ПЕРЕСМОТРА:
   - Фантастика(0.2) -> Гарри Поттер
     Причина: Слишком низкий коэффициент для типичной фантастики
   
   - Отсутствие связи "Биография" -> "Альберт Эйнштейн Биография"
     Причина: Основной жанр не связан с книгой
   
   - Отсутствие связи "Образование" -> "Sapiens"
     Причина: Основной жанр не связан с книгой

3. МАТЕМАТИЧЕСКИЕ НЕСООТВЕТСТВИЯ:
   - Гордость и предубеждение: сумма коэф = 1.4 > 1.0
   - Психология Влияния: сумма коэф = 1.1 > 1.0
   - Триллер №1: сумма коэф = 1.4 > 1.0

РЕКОМЕНДАЦИИ:
- Коэффициенты для ИЛИ-связей одного выхода не должны превышать 1.0 в сумме
- Связи должны отражать реальные жанровые соответствия
- Основные жанры книг должны иметь прямые связи с высокими коэффициентами
